SIMH is a collection of simulators for historically significant computers and hardware. Recreate the behavior of earlier systems, explore their architecture, and experiment with the software built for them.

Start exploring

From source to simulator

Use the repository's own instructions for the exact host, simulator and dependencies you need.

01 · Get the source

Clone the repository and review its README and license before building.

git clone https://github.com/ArkansasIo/simh.git

02 · Prepare your host

Install a supported compiler and the dependencies described by the project's build documentation for your OS.

03 · Build and read the docs

Use the documented make targets and simulator-specific instructions. Required historical ROMs or disk images may need to be sourced separately.

Need a particular machine?

Open the source tree and find the simulator directory and its local documentation.
